# Quniverze Web

Official company website for **Quniverze** — *We build software for businesses.*

Quniverze builds and operates software products, while helping businesses turn ideas into useful digital products.

## Products & Client Work

### Owned Products
- **NivaOps**: The operating system for modern rental properties.
- **Quniverze CRM**: A sales and project operating system for modern businesses.

### Client Services
- **Boven Frontier**: Digital flagship store and brand storytelling platform.
- **IGCC**: Corporate web platform and stakeholder portal.
- **StayB**: Direct booking engine and concierge platform.

## Tech Stack
- **Framework**: React 19 + TypeScript + Vite
- **Styling**: Tailwind CSS v4
- **Icons**: Lucide React
- **Typography**: Inter

## Getting Started

### Prerequisites
- Node.js 18+
- npm 9+

### Installation
```bash
npm install
```

### Development
```bash
npm run dev
```

### Production Build
```bash
npm run build
npm run preview
```
